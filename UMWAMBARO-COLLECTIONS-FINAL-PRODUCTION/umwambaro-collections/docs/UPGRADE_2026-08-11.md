# UMWAMBARO Collections — Catalog Upgrade

This build adds a simpler product model for a store that sells both new clothing and Chaguwa (used clothing).

## Product condition

The Admin product form now has one clear **Condition** field:

- New
- Chaguwa (Used)

The old **New arrival** checkbox has been removed. New Arrivals are automatically determined from `created_at` for the most recent 30 days.

Featured, Trending and Best Seller remain optional homepage merchandising controls.

## Existing Supabase project

Run `database/add-product-condition.sql` once in the Supabase SQL Editor. It adds the `condition` column and index without deleting existing products. Existing products default to `new`.

## Storefront

- Added Condition filter: All items / New / Chaguwa (Used).
- Product cards show New or Chaguwa badges.
- Recently added products can also show a `JUST IN` badge.
- Added a warm Rwanda-inspired color palette: cream, terracotta, mustard/gold, plum and emerald accents.
- Updated Next.js image configuration to allow Supabase Storage images.

## Images

The existing `product-images` Supabase Storage bucket is still used. Admin supports multiple image uploads and stores their public URLs in the product record.
